# Firebase hiện tại

Bản demo dùng Firebase Auth và Realtime Database trực tiếp, Cloudinary lưu ảnh. Hướng dẫn đang áp dụng là [BACKEND_SETUP](BACKEND_SETUP.md), trạng thái bàn giao là [BACKEND_HANDOVER](BACKEND_HANDOVER.md).

Không cần tạo Storage, SMTP, API riêng hoặc bật Blaze cho luồng hiện tại. Database tự có bản ghi khi thao tác trong app; không cần nhập món/đơn mẫu trước.
